# Конструктор проектов доверенностей

Страница собирает проект доверенности в порядке передоверия по основной доверенности и выдает DOCX на бланке организации-доверителя.

Паспортные данные представителей, дата и номер доверенности в проект не вносятся: их заполняет исполнитель при оформлении.

## Как пользоваться

1. Выбрать основную доверенность и бланк организации-доверителя.
2. Указать представителей: ФИО в именительном падеже (в текст попадет форма «уполномочивает кого»), должность с подразделением.
3. Отметить галочками полномочия, при необходимости сузить формулировку кнопкой «Изменить текст». Заявку с перечнем полномочий можно сверить с основной доверенностью кнопкой «Заявка / DOCX».
4. Проверить проект справа и нажать «Скачать проект на бланке (DOCX)».

## Проверка готового проекта

Кнопка «Проверка проекта» проверяет готовый проект доверенности, в том числе подготовленный коллегой и перенесенный в другую программу: файл DOCX, PDF с текстовым слоем или вставленный текст. Каждый абзац сопоставляется с пунктами основной доверенности (совпадает, сужен, изменен с добавлениями, нет в основной). Щелчок по абзацу или выделение фрагмента подсвечивает исходный пункт основной доверенности, щелчок по пункту показывает, где он в проекте. Проверяются ссылка на основную доверенность, срок, разделы и повторы. Файл читается на компьютере и никуда не отправляется.

Подробнее в окне «Справка» на самой странице: вкладки «Как пользоваться», «Возможности ПО» и «Версии».

## Где хранятся данные

Только в браузере на компьютере, где открыта страница (localStorage): текущая форма, черновики, добавленные основные доверенности и бланки. Страница ничего не отправляет в интернет, DOCX собирается на компьютере. Внешние соединения запрещены политикой безопасности страницы (Content-Security-Policy, `connect-src 'none'`). После первого открытия страницу можно сохранить и открывать как файл без интернета.

## Состав

- `index.html` - страница целиком (разметка, стили, код, встроенные основные доверенности, бланк и модуль чтения PDF).
- `robots.txt` - запрет индексации поисковиками.

Лицензии сторонних компонентов перечислены в `THIRD_PARTY.md`, текст лицензии pdf.js в `LICENSE-pdfjs.txt`.
